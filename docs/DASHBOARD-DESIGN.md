# 仪表盘布局规则（/web/ 首页）

> 状态：设计依据（现行页面结构与交互见 [WEB-CONSOLE.md](./WEB-CONSOLE.md) 的「仪表盘」一节）。

## 1. 定位

仪表盘展示**运行态**信息：区间请求量、成功率、耗时、token 消耗、各模型用量分布与活跃日历。
配置态信息（base_url、模型清单、渠道开关）在账号池页与设置弹窗。

Web 不提供网关启停控制。控制台是网关进程的一部分，页面持有进程生命周期等于把「自己正在跑的那个进程」交给一个 HTTP 端点；启停一律走本机终端 `mx`，页面只读展示网关状态。

## 2. 布局规则

- **纵向流**：单列纵向流，卡片间 `gap-3`、卡片内 `p-4`，标题用 `panel-title`。
- **滚动**：需要滚动的内容只在自己的容器里滚；KPI 与卡片超出视口时才整页滚动。
- **状态语义**：成功 = `--free`，失败 = `--danger`，慢 = `--warn`，未知 = `ink-faint`。
- **表意图形**：每卡头部带 lucide 图标（与导航同族），统一 16px。
- **可触达**：可点击的行用 `<button>` / `<tr>` 包裹整行，键盘可达（`focus-visible`）；hover 不承载信息（见 [WEB-CONSOLE.md](./WEB-CONSOLE.md)「交互铁律」）。

## 3. 栅格与断点

| 区域 | 窄屏 | lg（≥1024） | 2xl（≥1536） |
| --- | --- | --- | --- |
| KPI | 2 列 | 3 列 | 一行六格 |
| Token 趋势 | 单列 | 单列 | 单列 |
| 模型用量 + 一键接入 | 单列堆叠 | 左 8 / 右 4 等高 | 同左 |
| Token 活动 | 单列 | 单列 | 单列 |

KPI 在 2xl 才一行六格：1366 笔记本（xl 档）若六列，每列约 210px，tokens 副行折行会把卡高撑乱；1366 落 3 列 × 2 行。

## 4. 数据通道

| 端点 | 内容 | 刷新 |
| --- | --- | --- |
| `GET /web/api/overview` | 快照层：今日 KPI、渠道状态、模型池、最近请求 | 3–5 秒轮询 |
| `GET /web/api/usage?range=` | 区间层：KPI 六格、每日趋势、模型用量、热力图 | 切区间或手动刷新时重取 |
| `GET /web/api/state` | base_url、接入态、主题等配置态 | 布局层轮询 |

`/web/api/overview` 返回当天计数；`avg_duration_ms` 无样本返回 `null`；tokens 缺失不计 0。账号健康取内存快照，不触发真实重查（那是账号池页的职责）。

区间口径见 [USAGE-STATS.md](./USAGE-STATS.md)，页面结构与交互细节见 [WEB-CONSOLE.md](./WEB-CONSOLE.md)。
