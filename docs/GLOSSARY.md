# 术语表

核心概念统一定义，**每篇文档用这里的叫法**，别处不另起名字。
每个术语下一行 `_Avoid_:` 列出容易混的错误叫法与理由 —— 近义词不锁住，文档就会漂移。

新术语先在这里登记，再写进正文；正文里引用术语不重新定义（定义只在这里）。

## 网关

对外唯一入口。监听 `127.0.0.1:4412`，同时托管 `/v1/*` 协议与 `/web` 控制台。

_Avoid_: 「代理」「proxy」——它做的不只是转发，还挑渠道、管账号池、记账。

## 渠道

一个上游平台在册的一个接入实现（WorkBuddy / Loomy / Raccoon / TRAE / CatPaw 等），
代码落点 `packages/core/channels/<cid>`，目录 id 即 `<cid>`。

_Avoid_: 「厂商」——那是商业实体；「供应商」——gateway 对内是客户端的代理，方向反了。

## 账号池

同一渠道下的多组凭据集合。路由按「池内剩余额度之和」降序选，耗尽自动换号。

_Avoid_: 「账号列表」——重点不是罗列，是额度排序与切换策略。

## 模型家族

对外公布的模型名清单，唯一落点 `pool/model-family.ts`。共享层只允许在这一处出现模型名。

_Avoid_: 「模型池」——那是运行时的候选与选路机制，见 [POOL-ARCHITECTURE.md](./POOL-ARCHITECTURE.md)。

## 裸模型名

客户端请求时用的模型 id，不带 `<cid>/` 前缀。对外只有家族表公布的那两个。

_Avoid_: 「上游模型名」——上游写法（workbuddy 的 `deepseek-flash`、raccoon 的
`sn-deepseek-v4-1-flash-1017`）只在内部归一用，客户端写了照样 400。

## 候选渠道

某个模型当前可供给的渠道集合 = 渠道目录 `exposedIds()` 现算 ∪ 注册表声明（兜底）。

_Avoid_: 「可用渠道」——可用性还要看额度、冷却与熔断状态，不只是目录里有货。

## 换号

同一渠道内账号额度耗尽或失败时，切到该渠道下一个账号。**不是**换渠道。

_Avoid_: 「切换账号」——信息不足，没说明是同渠道内的动作。

## 冷却

账号或渠道撞到额度类错误后进入的暂停期，到期自动恢复；期间不下发请求。

_Avoid_: 「封禁」——冷却可自愈，不需要人工干预；「禁用」——容易与配置层的
`disabled` 混淆。

## 熔断

连败到阈值后整家渠道暂停，之后半开试探一次决定恢复还是继续关。

_Avoid_: 「拉黑」——熔断有自动半开与恢复路径，拉黑暗示永久。

## 代次

监督者每重生一次就 +1 的代计数。用于让 worker 与旧状态解绑、识别过期进程。

_Avoid_: 「版本号」——它是同一份代码的世代计数，不是发布版本（见 `docs/PROGRESS.md`）。

## 陈旧构建

网关进程加载的代码与当前源码不一致。`mx status --json` 的 `stale_build` 为 true 即命中。

_Avoid_: 「缓存问题」——不是缓存，是进程没重启；处置只有一条：build + restart。
